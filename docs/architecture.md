# Архітектура демо

Уся логіка в `index.html`: розмітка, стилі й скрипт без збірки та залежностей.

## Стан
Глобальний об'єкт `S` описує поточний дзвінок, `render()` щоразу перебудовує `#root` з нуля.

`S.state` приймає значення:
- `idle`: список контактів або, якщо заповнено `S.missed`, екран «Зайнято», «Без відповіді» чи «Пропущений дзвінок»;
- `ringing`: вихідний дзвінок, іде відлік таймера;
- `incoming`: вхідний дзвінок з кнопками «Прийняти» і «Відхилити»;
- `connected`: екран розмови.

Під час розмови екран залежить від прапорців `hold`, `peerHold`, `away`, `conn`, `q`, `mic`, `cam`,
`peerMic`, `peerCam`, `pip`. `clearAll()` скидає їх і зупиняє таймери та камеру.

## Контакти-сценарії
- `u2` відповідає через 3,5 с.
- `u4` одразу повертає «Зайнято».
- Решта не відповідають: через 8 с екран «Без відповіді».

## Панель сценаріїв
`sc()` малює кнопки: вхідний дзвінок, обрив зв'язку, співрозмовник зник, утримання,
слабкий сигнал, мікрофон і камера співрозмовника. Кнопки доступні лише у відповідному стані.

## Звуки
Генеруються через Web Audio (`SND`): гудки, «зайнято», мелодія вхідного, мелодія утримання.
`play(kind)` зупиняє попередній звук і запускає новий. Мелодію утримання чує той, кого тримають.

## Доступність
`announce()` пише коротке зведення стану в live-регіон `#live` для скрінрідерів.
