# Документація

Документація проєкту. Один документ на тему, імена файлів латиницею в `kebab-case`.

## Зміст

- [Архітектура](architecture.md): цільова архітектура застосунку, починаючи з фронтенду (Vue SPA).
- [Дизайн-система](design-system.md): кольори, типографіка, розміри, анімації, теми.
- [Сповіщення](notifications.md): пул сповіщень екрана розмови — джерела, групи, пріоритет, життєвий цикл і що бачить користувач.
- [Компоненти](components.md): каталог Vue-компонентів, їхні props, події й стани.
- [Структура проєкту](project-structure.md): папки репозиторію й що куди класти.
- [Бекенд](backend.md): стек сервера, структура `apps/server`, БД, токени, розгортання на Fly.io.
- [Сигналізація](signaling.md): контракт WebSocket між віджетом і сервером: команди, події, стани дзвінка, помилки.
- [Рекомендації LiveKit](livekit-recommendations.md): налаштування кімнати `livekit-client` (`adaptiveStream`, `dynacast`, обробка аудіо), що вже зроблено й що ні.
- [PWA та Web Push](pwa-and-push.md): архітектура Progressive Web App, життєвий цикл сповіщень про вхідні/пропущені дзвінки та бекенд-інтеграція.
- [Як влаштоване демо](demo.md): стани дзвінка, сценарії й звуки в `index.html`, сторінка демо з входом у `demo/`.
- [Локальний запуск](local-development.md): як підняти демо на :8080 і сервер на :8787.
