# Дизайн-система

Дизайн-токени фронтенду: кольори, типографіка, розміри, анімації. Значення взяті з демо (`index.html`).
Токени оголошуються в `web/src/app/styles/main.css` через `@theme` (див. [architecture.md](architecture.md#стилі)),
компоненти використовують лише їх, а не довільні значення на кшталт `bg-[#123456]`.
Опис компонентів у [components.md](components.md).

## Кольори

### Семантичні (залежать від теми)
| Токен | Утиліта | Світла | Темна | Для чого |
|---|---|---|---|---|
| `--color-bg` | `bg-bg` | `#eef0f6` | `#0b0d12` | фон сторінки |
| `--color-card` | `bg-card` | `#ffffff` | `#161a24` | картки, панелі |
| `--color-fg` | `text-fg` | `#12151f` | `#f3f5fa` | основний текст |
| `--color-mute` | `text-mute` | `#5b6478` | `#98a2b6` | другорядний текст |
| `--color-line` | `border-line` | `rgba(20,24,38,.1)` | `rgba(255,255,255,.12)` | рамки, роздільники |

### Акцентні (однакові в обох темах)
| Токен | Значення | Для чого |
|---|---|---|
| `--color-accent` | `#6366f1` | фокус, хвиля голосу, пульсація дзвінка |
| `--color-call-ok` | `#22c55e` | «Прийняти», «Подзвонити», «Продовжити» |
| `--color-call-bad` | `#ef4444` | «Завершити», «Відхилити», вимкнений мікрофон |
| `--color-warn` | `#fbbf24` | відновлення з'єднання, слабкий сигнал, співрозмовник зник |
| `--color-idle` | `#9aa3b2` | утримання |

Аватари: градієнт `#6366f1 → #a855f7`, текст білий.

### Екран дзвінка завжди темний
Екран дзвінка (вихідний, вхідний, розмова, результат) темний в обох темах, як у системних дзвонілках:
відео й аватар краще виглядають на темному фоні. Для нього окремі токени:

| Токен | Значення | Для чого |
|---|---|---|
| `--color-stage` | радіальний градієнт `#1e2340 → #0b0d12` | фон екрана дзвінка |
| `--color-stage-missed` | радіальний градієнт `#2a1e28 → #0b0d12` | екран пропущеного / «зайнято» |
| `--color-glass` | `rgba(255,255,255,.1)` + `backdrop-blur` | панель кнопок, таймер, статуси |

Текст на екрані дзвінка: `#f3f5fa`, другорядний `#98a2b6`.

## Типографіка
- Шрифт: `Inter, system-ui, -apple-system, "Segoe UI", sans-serif`.
- Цифри таймера: `tabular-nums`, щоб текст не стрибав щосекунди.

| Роль | Розмір | Приклад |
|---|---|---|
| Заголовок екрана | 22px, `tracking-tight` | «Дзвінки» |
| Ім'я на екрані дзвінка | 24–26px, `tracking-tight` | ім'я співрозмовника |
| Основний текст | 15–16px | ім'я в списку |
| Статус | 12.5–13.5px | «Відновлюємо з'єднання» |
| Підпис | 12px | «Залишилось 00:08» |

## Розміри й радіуси
| Що | Значення |
|---|---|
| Кнопка дзвінка | 54×54, коло |
| Аватар | 48 у списку, 104 на екрані дзвінка |
| Прев'ю своєї камери | 92px завширшки, 3:4, радіус 16 |
| Картка списку | радіус 28 |
| Екран дзвінка | 9:16, радіус 32 |
| Рядок списку | радіус 18 |
| Чіпи, статуси, таймер | `rounded-full` |
| Ширина застосунку | до 400px, поля 16px |

Мінімальна зона натискання — 44×44.

## Тіні
- Екран дзвінка: `0 30px 60px -20px rgba(0,0,0,.6)`.
- Кнопка «Прийняти»: `0 8px 24px rgba(34,197,94,.45)`; «Завершити»: `0 8px 24px rgba(239,68,68,.4)`.

## Анімації
| Назва | Що робить | Тривалість |
|---|---|---|
| `pulse` | кільця навколо аватара під час виклику | 1.6s, нескінченно |
| `wave` | хвиля голосу співрозмовника | 1s, смуги із затримкою 0.15s |
| `spin` | спінер відновлення | 0.8s |
| `blink` | крапка статусу | 1.2s |
| `in` | поява статусу згори | 0.25s |
| натискання кнопки | `scale(.92)` | 0.15s |

За `prefers-reduced-motion` нескінченні анімації вимикаються, лишаються лише зміни кольору й прозорості.

## Стани й доступність
- Фокус з клавіатури: `outline 2px` кольору `accent` з відступом 2px (`focus-visible`).
- Вимкнена кнопка: прозорість 35–40%, не реагує на натискання.
- Увімкнений перемикач (мікрофон, камера вимкнені): білий фон, темна іконка.
- Контраст тексту не нижче WCAG AA в обох темах.
- Враховуємо безпечні зони екрана (`env(safe-area-inset-*)`) на телефонах з вирізом.

## Іконки
Лінійні SVG 24×24, `stroke-width: 2`, закруглені кінці, колір `currentColor`.
Розмір 22px у кнопках, 14–16px у бейджах.
