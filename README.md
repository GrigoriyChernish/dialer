# Дзвонілка: демо фіч

Клікабельне демо інтерфейсу аудіо/відеодзвінків: список контактів, вихідний і вхідний дзвінок,
«зайнято», «без відповіді», пропущений дзвінок, екран розмови та сценарії
(обрив зв'язку, слабкий сигнал, утримання, мікрофон і камера співрозмовника).

У цьому прототипі все імітується в браузері: сервера й LiveKit немає, звуки генеруються через Web Audio.
Справжній бекенд (сигналізація, LiveKit) лежить у цьому ж репозиторії, `apps/server`, див. [`docs/backend.md`](docs/backend.md);
зміст документації в [`docs/README.md`](docs/README.md).

## Запуск

Один файл без збірки. Відкрийте `index.html` у браузері або підніміть локальний сервер
(потрібен для доступу до камери):

```bash
python3 -m http.server 8080
```

і відкрийте <http://localhost:8080>

Сторінка демо з входом і віджетом у кутку: <http://localhost:8080/demo/>.
Щоб подзвонити «іншому користувачу», відкрийте її ще в одній вкладці й увійдіть з іншим номером.
Зі справжнім сервером сигналізації (спершу запустіть `apps/server`): <http://localhost:8080/demo/?server=http://localhost:8787>.

Запуск сервера й налаштування `.env`: [`docs/local-development.md`](docs/local-development.md).

Онлайн: <https://grigoriychernish.github.io/dialer/> (публікується з гілки `dev`).
