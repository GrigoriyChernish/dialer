# Дзвонілка: демо фіч

Клікабельне демо інтерфейсу аудіо/відеодзвінків: список контактів, вихідний і вхідний дзвінок,
«зайнято», «без відповіді», пропущений дзвінок, екран розмови та сценарії
(обрив зв'язку, слабкий сигнал, утримання, мікрофон і камера співрозмовника).

Усе імітується в браузері: сервера й LiveKit немає, звуки генеруються через Web Audio.

## Запуск

Один файл без збірки. Відкрийте `index.html` у браузері або підніміть локальний сервер
(потрібен для доступу до камери):

```bash
python3 -m http.server 8080
```

і відкрийте http://localhost:8080

Сторінка демо з входом і віджетом у кутку: http://localhost:8080/demo/.
Щоб подзвонити «іншому користувачу», відкрийте її ще в одній вкладці й увійдіть з іншим номером.
