# Десктопний застосунок: вхідний дзвінок

`apps/mobile` це Tauri 2: на десктопі (macOS, пізніше Windows) він пакує `apps/web` у вікно й живе в треї. Вхідний дзвінок показує окреме міні-вікно, як `CallStyle` на Android ([pwa-and-push.md](pwa-and-push.md#android-застосунок-tauri-callstyle-і-fcm)).

## Поведінка

- **Міні-вікно** «Вхідний дзвінок» (дизайн: компонент `Incoming Window` у `Components · Base`, екрани `Flow · Incoming call · desktop`): 392 × 148, без рамки, поверх усіх вікон і на всіх робочих столах, правий верхній кут основного монітора, не забирає фокус, перетягується. Аватар, ім'я, «ВХІДНИЙ ВИКЛИК» і дві кнопки: «Відхилити» (червона) й «Прийняти» (зелена). Тема за налаштуванням застосунку.
- **Коли показується.** Основне вікно приховане (закрите в трей) або без фокусу (`away()` в `entries/app.ts`: `visibilityState === 'hidden'` чи `!document.hasFocus()`). Коли воно в фокусі, міні-вікна немає: екран дзвінка в самому застосунку й системна мелодія.
- **Мелодія.** Грає Rust (`src-tauri/src/incoming.rs`): на macOS системний звук `Submarine` через `afplay` по колу, зупиняється при відповіді, відхиленні, кінці дзвінка чи через 60 с. Вбудований рінгтон (`Sounds`) на десктопі вимкнено. На Windows мелодії ще немає (беклог).
- **«Прийняти»** закриває міні-вікно, показує основне вікно й передає йому подію `callstyle` `answer`: застосунок викликає `call.answerFromPush`. **«Відхилити»** закриває вікно й передає `decline`: застосунок завершує вхідний через сигналізацію.
- **Закриття.** Міні-вікно закривається само, коли дзвінок скінчився (скасовано, прийнято на іншому пристрої, таймаут `expiresAt`), або коли основне вікно отримало фокус.
- **Пропущений дзвінок**, поки застосунок не перед очима: системне сповіщення «Пропущений дзвінок» (плагін `tauri-plugin-notification`); у самому вікні чекає звичайний екран «Ви не відповіли на вхідний».

## Як влаштовано

- **Команди Rust** (`incoming.rs`, лише desktop): `show_incoming(callId, name, expiresAt)`, `hide_incoming(callId)`, `start_ringtone`, `stop_ringtone`, `incoming_action(kind, callId)`. Вікно `incoming` створюється кодом (`WebviewWindowBuilder`) з адресою `incoming.html?callId=…&name=…`; стан `Incoming` тримає поточний дзвінок (старий таймер не закриє вікно нового дзвінка) і прапорець мелодії.
- **Вікно закриття.** Обробник `CloseRequested` у `lib.rs` ховає в трей лише вікно `main`; інші вікна закриваються як звичайно.
- **Веб.** `shared/native/callstyle.ts` має десктопну гілку (`isDesktopCallStyle`: Tauri без Android-моста): `show/cancel/startRingtone/stopRingtone` викликають команди Rust через `tauriInvoke` (`shared/native/notify.ts`). Дії повертаються на `window` подією `callstyle` (`detail.type`: `answer`, `decline`), тією самою, що й на Android, тож обробка в `entries/app.ts` спільна. Сторінка міні-вікна: `incoming.html`, `src/entries/incoming.ts`, `features/call/IncomingWindow.vue`.

## Досяжність

- Вхідний приходить звичайним WebSocket, тож застосунок має бути запущений: при закритті вікно йде в трей і тримає сокет. Автозапуск при вході в систему й захист від App Nap (macOS) ще не зроблено (беклог).
- Після явного «Вийти» (Quit) у треї пристрій недосяжний, але сервер дзвонить на всі пристрої користувача, тож дзвінок піде на інший (телефон). Аналога FCM для нативного десктопного застосунку немає; можливі APNs (macOS) і WNS (Windows), вони вимагають акаунта розробника, підпису й нативного коду (беклог).
- Браузерна PWA отримує вхідні через Web Push ([pwa-and-push.md](pwa-and-push.md)), але в WebView Tauri Push API не працює.

## Перевірка

Сервер локально, `corepack pnpm --filter @dialer/mobile dev`, увійти, закрити вікно (піде в трей), подзвонити з іншого користувача: з'являється міні-вікно й грає мелодія; «Прийняти» відкриває розмову, «Відхилити» дає `rejected`, скасування закриває вікно саме. Для збірки застосунку на справжній сервер (`Dialer Stage.app`) див. [stage-builds.md](stage-builds.md).
